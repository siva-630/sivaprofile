# **App Name**: StudioSpark

## Core Features:

- Hero Section: Interactive hero section with animated background gradients, name, and tagline.
- About Me: Parallax scrolling bio section with a blurred background image and brief introduction.
- Skills Showcase: Skill cards that display on hover using tooltips and reveal further detail.
- Projects Display: A masonry grid of interactive project cards. Supports video previews, links and descriptive project tags.
- Education Timeline: Animated timeline showing education and key achievements.
- Contact Interface: Interactive contact form featuring floating labels and a loading animation upon submission. Also showcases stylized social media icons.
- AI Tagline Generator: A tool that offers dynamically generated personalized tagline suggestions for the Hero Section, assisting users to present their portfolio's main intention.

## Style Guidelines:

- Primary color: Indigo (#3F51B5) for a professional and modern feel.
- Background color: Light gray (#F5F5F5), almost white, for spaciousness and clarity.
- Accent color: Teal (#009688) to provide a contrasting, engaging call to action.
- Emphasize readability with the clean and modern Roboto font.
- Consistent, minimalistic Material Design icons to enhance UI clarity.
- Utilize Material Design grids to create a structured and responsive design.
- Incorporate subtle, smooth animations, like card hover effects, to add interactivity and polish.
